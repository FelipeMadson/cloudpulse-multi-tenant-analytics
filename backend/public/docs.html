CloudPulse Multi-Tenant Analytics

Enterprises struggle to monitor multi-tenant applications with granular data isolation and real-time observability.

OpenAPI 3.0.3 • Multi-Tenant Enterprise • Zero External Dependencies

Rotas da API REST

GET /health
Sonda de integridade operacional, uptime e contagem de tenants.
curl -X GET http://localhost:3000/health
GET /metrics
Telemetria operacional nativa no padrão Prometheus.
curl -X GET http://localhost:3000/metrics
GET /api/v1/tenants
Listagem de inquilinos com isolamento estrito e quotas ativas.
curl -X GET http://localhost:3000/api/v1/tenants -H "Authorization: Bearer sk_live_enterprise_demo_key_999"
POST /api/v1/resources
Criação transacional de recurso com Write-Ahead Log e emissão de webhook.
curl -X POST http://localhost:3000/api/v1/resources -H "Authorization: Bearer sk_live_enterprise_demo_key_999" -H "Content-Type: application/json" -d '{"title":"Cluster Alpha","data":{"nodes":8}}'
POST /api/v1/stream/events
Ingestão de alta vazão no motor de streaming para cálculo de percentis de latência.
curl -X POST http://localhost:3000/api/v1/stream/events -H "Authorization: Bearer sk_live_enterprise_demo_key_999" -H "Content-Type: application/json" -d '{"source":"iot-gateway","eventType":"telemetry","durationMs":24,"statusCode":200}'
GET /api/v1/stream/analytics
Agregação estatística de percentis (P50, P95, P99) em janela deslizante.
curl -X GET http://localhost:3000/api/v1/stream/analytics -H "Authorization: Bearer sk_live_enterprise_demo_key_999"
